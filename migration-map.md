## Deliberately deferred from the first safe build

The live site is not replaced, DNS and hosting are not altered, and no WordPress content is deleted. A production migration needs explicit authorisation once the parallel build is reviewed and a redirect plan is approved. Features that require an external service, such as a real newsletter, transactional contact form delivery, external site search indexing and analytics, are represented by accessible routes or reserved configuration—not invented functionality.
